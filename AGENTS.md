## Mathematical notation

- In user-facing responses, write equations as single-line plain text that remains readable without Markdown or LaTeX rendering.
- Use descriptive variable names or explicit subscripts such as `r_L`, `I_new`, and `I_old`.
- Write division inline with `/` and add parentheses to make precedence unambiguous.
- Put multi-step calculations in a fenced `text` block, one complete equation per line.
- Use rendered LaTeX only when the user explicitly requests it; if used, keep the plain-text equation as the primary representation.
